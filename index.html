                    3.1
                    
Securify

                    
Android app · Kotlin · Compose

                


                

                    

                        
Yet another root checker, done properly.

                        
It looks for Magisk and KernelSU modifications, checks Play Integrity verdicts through its backend, and lays out the device details people actually ask about: ABI, kernel version, build fingerprint, security patch level. Material 3 Expressive with dynamic color, and an AMOLED theme for the people who care.

                        
Want it without ads or tracking? That's the GitHub build. Every APK there is signed with the certificate below, so you can check it yourself with apksigner verify.

                    3.2
                    
Iconsax Compose

                    
Compose Multiplatform library · GPL-3.0

                


                

                    

                        
Over a thousand Iconsax icons, ready to drop into Compose.

                        
The full Iconsax set by Vuesax, generated into Kotlin so you can hand any icon to the standard Icon composable. Icons are grouped by style, and arrows that should flip in right-to-left layouts live under AutoMirrored.

                        
Fig. 1 is drawn the same way: 24 × 24 viewport, round caps and joins, one stroke.
